[약수가 세 개인 수 / trail0.Codetree101] 분석
1. 문제 핵심 요약
입력

정수 start, end 두 개가 공백으로 주어진다.

출력

start 이상 end 이하의 정수 중 약수가 정확히 3개인 수의 개수를 출력한다.

문제 목표

주어진 범위의 정수들 중 약수의 개수가 정확히 3개인 수의 개수를 구한다.

2. 제약 조건 (Constraints)
항목	내용
시간 제한	1000ms (1초)
메모리 제한	80MB
입력 범위	start ≤ end ≤ 1000
시간 복잡도 판단

일반적으로 1초 ≈ 1억 연산 가능하다.

최악의 경우 연산량

1000 × 1000 = 1,000,000

→ 약 100만 연산으로 충분히 통과 가능하다.

3. 알고리즘 선택
선택한 알고리즘

완전탐색 (Brute Force)

이유

현재 반복문 학습 단계이므로
각 숫자의 약수를 직접 세는 방식이 문제 의도와 학습 목표에 가장 적합하다.

예상 시간 복잡도

O(N²)

N ≤ 1000 이므로 충분히 해결 가능하다.

4. 핵심 로직 (Core Logic)

범위 start ~ end의 모든 숫자를 검사하면서
각 숫자의 약수 개수를 계산한다.

어떤 수 i의 약수는

1 ~ i

사이의 수 중에서

i % j == 0

을 만족하는 수이다.

약수를 발견할 때마다 개수를 증가시키고
최종적으로 약수 개수가 3개이면 정답에 포함한다.

예시

4의 약수

1
2
4

→ 총 3개

5. 엣지 케이스 (Edge Cases)

start = 1 인 경우
→ 1의 약수는 1개이므로 조건을 만족하지 않는다.

범위 내에 조건을 만족하는 수가 없는 경우
→ 0 출력

end = 1000이어도 완전탐색 가능

6. Pseudo Code

start, end 입력

count = 0

for i in start ~ end
 divisor = 0

 for j in 1 ~ i
  if i % j == 0
   divisor += 1

 if divisor == 3
  count += 1

count 출력

💻 코드 구현
start, end = map(int, input().split())

count = 0

for i in range(start, end + 1):
    divisor = 0

    for j in range(1, i + 1):
        if i % j == 0:
            divisor += 1

    if divisor == 3:
        count += 1

print(count)
🔍 코드 동작 설명

1️⃣ start ~ end 범위의 모든 수 탐색

for i in range(start, end + 1)

2️⃣ 각 수의 약수 개수 계산

for j in range(1, i + 1)

3️⃣ 약수 조건

i % j == 0

4️⃣ 약수 개수가 3개이면 정답 증가

🤖 AI 점검 (추가로 알게 된 개념)

완전탐색으로도 해결할 수 있지만
이 문제는 수학적 성질을 이용하면 더 간단하게 풀 수 있다.

약수 개수의 특징

약수는 일반적으로

(a, n/a)

형태의 쌍으로 존재한다.

그래서 대부분 약수 개수는 짝수이다.

약수가 홀수개인 경우

약수가 홀수개가 되는 경우는

제곱수

일 때이다.

예

4 → 1,2,4
9 → 1,3,9

약수가 정확히 3개인 수

약수가 정확히 3개가 되려면

n = p²

여기서

p = 소수

예

4 = 2²
9 = 3²
25 = 5²
49 = 7²

약수

1, p, p²

→ 정확히 3개

⭐ 이번 문제에서 배운 핵심

반복문을 이용한 완전탐색으로 약수 개수 계산

약수 문제에서 제곱수의 성질

약수가 3개인 수 = 소수의 제곱수

약수 문제
↓
제곱수
↓
소수 제곱수

이 패턴은 이후 수학 문제에서 자주 등장한다.

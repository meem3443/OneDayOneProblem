# [잔해물을 덮기 위한 사각형 최소 넓이] 분석

## 1. 문제 핵심 요약

- [ ] 입력은 무엇인가? (자료형, 개수): 첫번째 줄에 첫번째 직사각형에 해당하는 좌측하단 좌표, 우측상단 좌표 (x1,y1) (x2,y2)가 공백을 두고 주어짐
      두번째 줄에 두번 째 직사각형에 해당하는 좌측하단 좌표와 우측하단좌표 (x1,y1) (x2,y2)가 공백을 두고 주어짐
- [ ] 출력은 무엇인가? (포맷, 정답 조건): 첫 번째 줄에 남아있는 첫 번째 직사각형의 잔해물을 덮기위한 최소 직사각형의 넓이를 출력하라.
- [ ] 문제의 목표를 한 문장으로 정리하면?: 첫번째 직사각형과 두번째 직사각형의 겹치는 부분을 첫번째 직사각형에서 뺀뒤에 남은 넓이를 모두 덮는 직사각형의 넓이를 구하라.

## 2. 제약 조건 (Constraints) 분석

- 시간 제한: 1000ms
- 메모리 제한: 100MiB
- 입력 크기(N): -1000 <= x1,x2 <= 1000, -1000 <= y1,y2 <= 1000
- 값의 범위: Integer

## 3. 알고리즘 선택 & 복잡도 예상

- [ ] 예상 시간 복잡도: O(1)
- [ ] 선택한 자료구조: 배열
- [ ] 선택한 알고리즘: 단순계산
- [ ] 근거: 좌표는 무조건 두개씩 전달하니 O(1)

## 4. 엣지 케이스 (Edge Cases) & 예외 처리

- case : 1 겹쳐지지 않을때 : 첫번째 직사각형의 넓이 [겹쳐지지 않는경우는 크게 세가지, 옆으로 딱붙어있거나, 아래로 딱붙어있거나, 아예 붙어있지 않거나]
- case : 2 세로끝을 포함하여 완전히 겹쳐질때 : 첫번째 직사각형의 넓이 - 겹쳐진 부분의 넓이
- case : 3 가로끝을 포함하여 완전히 겹쳐질때 : 첫번째 직사각형의 넓이 - 겹쳐진 부분의 넓이
- case : 4 세로나 가로끝을 포함하여 겹쳐지지 않고 일부분 겹칠때 [대표적으로는 중간을 꿰뚫는경우]

# [문제 이름/번호] 분석

## 1. 문제 핵심 요약

- [ ] 입력은 무엇인가? : 첫번째 줄에는 만들어야하는 그룹의 수를 나타내는 N, 두번째 줄에는 2N개의 숫자가 공백을 두고 전달
- [ ] 출력은 무엇인가? (포맷, 정답 조건): 각 그룹의 원소의 합의 최대 값이 가장 작아 질 수 있도록 N개의 그룹을 적절히 만들었을때 최댓값 출력
- [ ] 문제의 목표를 한 문장으로 정리하면?: 각원소의 값 조합의 최대값을 구할때, 각 조합중 최대값 이 가장 작아질때의 값을 출력하라.

## 2. 제약 조건 (Constraints) 분석

- 시간 제한: 1000ms초
- 메모리 제한: 80MiB
- 입력 크기(N):
  - 1 <= N <= 1000
  - 1 <= 원소 <= 1000
- 값의 범위: Integer

## 3. 알고리즘 선택 & 복잡도 예상

- [ ] 예상 시간 복잡도: O(NlogN)

## 4. 엣지 케이스 (Edge Cases) & 예외 처리

- [] 모든 값이 같을때 : 일반적인 방법과 같이 처리할 수 밖에없음.

## 5. 로직 설계 (Pseudo-code)

1. 입력값을 통해서 오름차순으로 값을 정렬시킨후 배열에 저장한다.
2. 정렬된 배열의 맨앞과, 맨뒤를 더하여 새로운 배열에 저장한다.
3. 해당 배열에서 가장 작은 값을 출력한다.

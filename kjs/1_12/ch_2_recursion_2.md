### 1. 문제 이름 (Problem Name)

각 자리 숫자의 제곱

- 개발 블로그 링크

### 2. 사용 개념 (Concepts Used)

- 재귀

### 3. 문제 이해 및 초안 (Drafting)

- 8자리 이하의 정수 N이 주어지면 재귀함수를 이용하여 각 자리 숫자의 제곱의 합을 출력하는 프로그램을 작성해보세요.

### 4. 로직 설계 (Logic Design)

-일반적인 상황-
정수 N 입력받기
[N을 자릿수하나당 하나의 원소로 분해한 리스트로 변경]
결과값 = 0
for i < 리스트 길이:
결과값 += 원소^2
print(결과값)

-재귀 사용-
정수 N 입력받기

if 정수 == 0:
return
재귀함수(정수 / 10, 결과값)
결과값 = 결과값 + 정수^2

### 5. 실제 코드 (Actual Code)

```
def recursionSum(N: int, result: int):
    if N == 0:
        return result
    return recursionSum(N // 10, result + (N % 10)**2)


N = int(input())
print(recursionSum(N, 0))
```

### 6. 시행착오 (Trial & Error)

자릿수 분리 방식 (논리)

Error: 나누는 수(10, 100...)를 키워서 자릿수를 떼어내려 함. (123 % 100 = 23 문제 발생)

Fix: 입력된 정수 자체를 10으로 나눠(//) 꼬리를 잘라내며 숫자를 줄여가는 방식 채택.

재귀 전달 인자 (Parameter)

Error: 다음 재귀 함수에 N % 10(나머지)을 넘겨줌. (몸통은 사라지고 꼬리만 남음)

Fix: 현재 자리는 계산하고, 남은 몸통인 **N // 10(몫)**을 다음 재귀로 넘김.

계산 대상의 착각

Error: N _ N을 더함. (줄어든 숫자 전체를 제곱함, 예: 12 _ 12)

Fix: (N % 10) \*\* 2 (방금 떼어낸 마지막 한 자리만 제곱함).

종료 조건 (Base Case)

Error: if N % 10 == 0: (10, 20 처럼 끝자리가 0이면 오작동)

Fix: if N == 0: (숫자가 완전히 0이 되어 더 이상 쪼갤 수 없을 때 종료).

반환값 처리 (Return)

Error: 내부에서 계산만 하고 return을 안 함. (None 발생)

Fix: 재귀함수는 부메랑. 호출한 곳으로 계산된 값을 반드시 **return**으로 돌려줘야 함.

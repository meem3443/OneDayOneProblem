# [문제 이름/번호] 분석

## 1. 문제 핵심 요약

- [ ] 입력은 무엇인가? (자료형, 개수): 첫줄엔 m1, d1, m2, d2 두번째 줄엔 요일이 이니셜로 전달
- [ ] 출력은 무엇인가? (포맷, 정답 조건): 정수
- [ ] 문제의 목표를 한 문장으로 정리하면?: 윤년 2024년 m1월 d1일이 월요일이면 2024년 m2월 d2까지 A요일은 몇번 등장하는지 구하는 프로그램을 작성할것. (m2,d2는 m1, d1보다 앞서지 않음)

## 2. 제약 조건 (Constraints) 분석

- 시간 제한: 1000ms초
- 메모리 제한: 80MiB
- 입력 크기(N): Int(4) String(3)
- 값의 범위: 정수

## 3. 알고리즘 선택 & 복잡도 예상

- [ ] 예상 시간 복잡도: O(1)
- [ ] 선택한 자료구조: 배열
- [ ] 선택한 알고리즘: (Greedy, DP, BFS/DFS, 이분탐색 등)
- [ ] 근거: 요일 일자가 더 늘어나지 않기 때문에 0(1)

## 4. 엣지 케이스 (Edge Cases) & 예외 처리

- [] 시작년도가 2029인 만큼 윤년 포함하여 계산

## 5. 로직 설계 (Pseudo-code)

1. 각 월별 값 배열로 선언 dayPerMonth
2. m1,d1 m2,d2 까지의 각각 일자 계산 (Total1, Total2) [for i in range(m-1): total = total[dayPerMonth[i]]]
3. (Total2-Total1) 계산
4. (Total2-Total1 값) - 목표요일 가중치) // 7 출력

## [양수 직사각형의 최대 크기] 분석

* **입력**: $N \times M$ 격자 
* **출력**: 모든 값이 양수로 이루어진 직사각형의 최대 크기

### 제약
* **시간**: 1000ms  
* **메모리**: 80MiB

### 알고리즘
* 격자를 전부 순회
  > $O(N^2)$
* 해당 지점을 좌측상단으로 두고, 세로(row) 확장하며 순회
  > 매 row마다 가로(col) 확장하며 양수 확인  
  > 음수 발견 시 안쪽 for문 중단, 해당 col을 max_col로 저장  
  > 다음 row는 max_col 까지만 탐색, max_col=0 이면 바깥 for문도 중단  
  > 전부 양수라 가정하면 최대 크기 $N \times M$ → $O(N^2)$  
* 전체 $O(N^4)$

### 보완: 히스토그램 + 스택 → $O(NM)$
> 💡 *Claude (claude.ai)의 도움을 받아 작성되었습니다.*

위 알고리즘은 최악의 경우 (전부 양수인 격자) 가지치기가 전혀 안 돼 $O(N^4)$ 그대로입니다.

**개선:** 각 칸마다 "위로 연속된 양수의 개수" 로 히스토그램을 만들면, 문제가 **"히스토그램에서 최대 직사각형 넓이"** 로 바뀝니다.

**1단계: 히스토그램 만들기**
```
격자:          히스토그램:
1  2  3        행0: [1, 1, 1]
1 -1  4   →    행1: [2, 0, 2]  ← 음수면 0으로 리셋
1  2  3        행2: [3, 1, 3]
```

**2단계: 스택으로 히스토그램 최대 직사각형**
> 막대를 스택에 쌓다가, 현재 막대가 top 보다 낮아지는 순간 pop 하며 넓이 확정
> `넓이 = 높이 × (오른쪽 경계 - 왼쪽 경계 - 1)`
```
행2 히스토그램: [3, 1, 3]

i=0: push(0)                        스택: [0]
i=1: 1<3 → pop(0), 넓이=3×1=3      스택: []
     push(1)                        스택: [1]
i=2: 3>1 → push(2)                 스택: [1, 2]

배열 끝:
  pop(2): 넓이=3×(3-1-1)=3         스택: [1]
  pop(1): 넓이=1×3=3               스택: []

최대 = 3
```

> 행마다 $O(M)$ → 전체 $O(NM)$

| 전체 복잡도 | 기존 | 개선 |
|---|---|---|
| | $O(N^4)$ | $O(NM)$ |

&nbsp;

> [!NOTE]
📝 *memo:* 왼->오 순서대로 오른쪽이 나보다 작을 경우(직사각형 성립X일 경우) 바로 pop과 동시에 넓이를 계산  
  >> 팝 되는 시점이 해당 직사각형의 가로 넓이를 결정（ 현재 ｉ － 스택의 top -1)  
  >> 여기에 팝 되는 해당 막대의 높이를 곱한 게 넓이

### 로직 설계  
* 행마다 히스토그램 갱신  
  > 양수면 이전 행 값에 +1, 음수면 0으로 리셋  
* 갱신된 히스토그램에 스택 알고리즘 적용  
  > 막대를 스택에 push 하다가 현재 막대가 top 보다 낮아지면 pop 하며 넓이 확정  
  > `넓이 = 높이 × (오른쪽 경계 - 왼쪽 경계 - 1)`  
  > 배열 끝에서 스택에 남은 막대 처리  
* 전체 행 반복 → $O(NM)$

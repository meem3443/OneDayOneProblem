## [1차원 바람] 분석

* **입력**: N*M 격자, Q번의 바람(r:행, d:방향)
* **출력**: T초 후 베이어 벨트의 모습



### 제약
* **시간**: 1000ms  
* **메모리**: 80MiB

&nbsp;

### 알고리즘
* 이하 내용을 총 Q번 반복
* r행 밀고당기기 수행 후(O(M)), r-1, r+1행에 같은 열 같은 숫자가 있는지 탐색(총 2M번)
  > 같은 숫자가 있을 경우: > 해당 행들도 반대 방향으로 바람 수행, 끝까지 반복(O(M)를 최대 N/2번 = $O(NM))$ )
* 총 시간복잡도 $O(QNM)$

&nbsp;

### 예외처리
N=1: 전파 고려 X  
M=1: 바람 영향 X  
Q=0: 그대로 출력  

### 로직 설계
1. 입력받음
2. r행 shift수행, 위쪽과 아래쪽 두 방향으로 전파 시작
   > 위: if a[r,i] == a[r-1,i]: is_shift =True 후 방향을 바꿔 shift수행, r의 값을 감소시키며 반복
   > 아래: 같은 방식으로
3. 모든 바람에 대해 2번 수행
4. 최종 a 출력

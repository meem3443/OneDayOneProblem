## [겹쳐지지 않는 두 직사각형] 분석

* **입력**: $N \times M$ 격자 
* **출력**: 격자 안에서 겹치지 않게 두 직사각형을 잡았을 때, 얻을 수 있는 최대의 값

### 제약
* **시간**: 2000ms  
* **메모리**: 80MiB

### 알고리즘
* 가로: 1\~(N-1), 세로: 1\~(M-1) 로 증가해가며 격자를 두 영역으로 나눈다.
  >각각의 for문 = $O(N)$
* 각자의 영역에서의 지점 순회
  >최대 (N-1)*(M-1) 횟수 방문   > $O(N^2)$
* 각 지점을 직사각형의 좌측상단으로 두고 가능한 직사각형 탐색&최대값 구하기
  > $O(N^2)$
* $O(N) \times O(N^2) \times O(N^2) = O(N^5)$

### 보완: 2D Prefix Sum → $O(N^4)$
> 💡 *이하 내용은 Claude (claude.ai)의 도움을 받아 작성되었습니다.*

**개선:** 미리 2D 누적합 배열을 만들면 직사각형 합을 $O(N^2) \to O(1)$ 로 줄일 수 있습니다.

$$\text{sum}(r1,c1,r2,c2) = P[r2][c2] - P[r1-1][c2] - P[r2][c1-1] + P[r1-1][c1-1]$$

| 전체 복잡도 | 기존 | 개선 |
|---|---|---|
| | $O(N^5)$ | $O(N^4)$ |
  
&nbsp;

> [!NOTE]
📝 *memo:* 기존에 for문 안에서 했던 계산( $O(N^4)$ )이 밖으로 나와서 전체 시간복잡도가 for문( $O(N)$ )만큼 줄어듦

### 추가 보완: 2D 카데인 + 점진적 갱신 → $O(N^3)$
> 💡 *이하 내용은 Claude (claude.ai)의 도움을 받아 작성되었습니다.*

**`top[k]`** = 1\~k행 영역 안의 모든 직사각형 중 최대 합 (bottom/left/right 동일)
  > **`bottom[k]`** = k\~N행 영역 안의 모든 직사각형 중 최대 합  
  > **`left[k]`** = 1\~k열 영역 안의 모든 직사각형 중 최대 합  
  > **`right[k]`** = k\~M열 영역 안의 모든 직사각형 중 최대 합


직사각형은 **(r1, r2, c1, c2)** 로 결정되는데, r1·r2를 고정하면 c1~c2 선택은 **카데인 알고리즘**이 $O(M)$ 에 처리합니다.

**카데인 알고리즘** (1D 최대 연속 부분합)
$$\text{cur} = \max(\text{arr}[i],\ \text{cur} + \text{arr}[i])$$
> 이전 구간을 이어받는 것 vs 새로 시작하는 것 중 큰 쪽 선택. 배열을 한 번만 순회 → $O(M)$

**`colSum[j]`** = r1~r2행의 j열 합. r2가 늘어날 때 해당 행만 더해 재활용합니다.
```
r1=1 고정:
  r2=1: colSum = 1행           → 카데인
  r2=2: colSum += 2행          → 카데인
  r2=3: colSum += 3행          → 카데인

r1=2 고정: (colSum 초기화)
  r2=2: colSum = 2행           → 카데인
  r2=3: colSum += 3행          → 카데인
...
```

**시간복잡도**

| 단위 | 복잡도 | 이유 |
|---|---|---|
| 한 쌍 (r1, r2) | $O(M)$ | colSum 갱신 $O(M)$ + 카데인 $O(M)$ |
| 전체 쌍의 수 | $O(N^2)$ | $N(N+1)/2$ 개 |
| `top` 배열 전체 | $O(N^2M)$ | $O(N^2) \times O(M)$ |
| 4개 배열 + 정답 계산 | $O(N^2M + NM^2)$ | left/right는 $O(NM^2)$ |

$$O(N^2M + NM^2) = O(NM(N+M)) \approx O(N^3) \quad (N \approx M)$$


&nbsp;

> [!NOTE]
📝 *memo:* 한 쌍 * 전체 쌍의 수 = `top` 배열 전체 시간복잡도(다른 배열도 마찬가지)  
    > 정답 계산은 for문 두 번/ 각각의 for문 안에서 배열 2개(top/bottom 또는 left/right)을 순회하며 최대값 고르기 > $O(N + M)$ 라 $O(N^3)$ 에 비해 무시됨

### 엣지 케이스 (Edge Cases) & 예외 처리
음수만 있을 경우: 카데인 초기값을 arr[0]으로 설정  
직사각형의 크기는 1*1 부터 N*M보다 작은 형태로만  

  
### 로직 설계
1. top/bottom/left/right 배열 계산
    > r1을 고정하고 r2를 r1~N 까지 순회 (이중 for문)
    > r2가 늘어날 때마다 colSum 에 해당 행만 추가
    > kadane(colSum) 으로 최대 직사각형 합 갱신
2. 분할선 k 를 순회하며 정답 계산
    > 수평: top[k] + bottom[k+1]
    > 수직: left[k] + right[k+1]
3. ans = max(ans, top[k] + bottom[k+1], left[k] + right[k+1])

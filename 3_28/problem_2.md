### **Trail.0 논리 연산자**

### **1. 문제 독해: 무엇을 묻는가?**

> 코드를 생각하기 전, 한국어로 완벽하게 문제를 이해하는 단계입니다.
> 
- [ ]  이 문제가 나에게 요구하는 최종 결과는 무엇인가?: 입력받은 정수가 홀 수 이면서 3의 배수인지 또는 짝수이면서 5의 배수이면 ture 출력 아니면 false 출력 

- [ ]  출제자의 의도는 무엇일까? (어떤 개념을 아는지 확인하려고 낸 문제일까?): 논리연산자를 확인할 수 있는지

### **2. 논리 및 수학적 설계**

> 무작정 코드를 치는 것이 아니라, 어떤 원리로 풀리는지 논리적으로 구성합니다.
> 
- [ ]  문제를 해결하기 위해 필요한 수학적 규칙이나 논리적 흐름은 무엇인가?: 논리 연산자를 사용한다.
- [ ]  왜 그 규칙이 적용되어야 하는가? (나만의 언어로 타당성 설명): 문제의 의도에 가장 잘 맞는다.

### **3. 기초 문법 및 데이터 타입 고민하기**

> 필요한 도구(문법, 타입)를 미리 꺼내놓는 단계입니다.
> 
- [ ]  필요한 데이터 타입(Data Type)은 무엇인가? (ex. 정수, 문자열, 배열 등): 정수
- [ ]  왜 이 데이터 타입을 사용해야 하는가?: 문제에서 정수만을 취금
- [ ]  이 문제를 풀기 위해 꼭 필요한 기초 문법은 무엇인가? (ex. 반복문(for/while), 조건문(if), 특정 내장 함수 등): if문, OR 연산자
- [ ]  왜 그 문법이 필요한가?: 함수를 정의한 뒤 반복문을 사용해야 문제의 의도에 부합한다.
### **4. 단계별 로직 구성 (Pseudo-code)**

> 프로그래밍 언어가 아닌, 사람이 이해할 수 있는 순서도로 작성합니다.
> 
1. **입력:** (어떤 값을 어떻게 받을 것인가?)
자연수 N

2. **처리:** (어떤 순서로 계산하고 조작할 것인가?)
N이 홀수이면서 3의 배수인지 확인하거나 짝수이면서 5의 배수인수를 확인
3. **출력:** (최종 결과를 어떻게 보여줄 것인가?)
N이 홀수이면서 3의 배수인지 확인하거나 짝수이면서 5의 배수인수를 확인하여 맞다면 true 출력 아니면 false 출력

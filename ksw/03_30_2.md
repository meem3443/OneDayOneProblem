### **6. 로직 설계 (Pseudo-code)**
3줄의 입력을 하나의 배열로 만들어 놓고 t의 값에 따라서 출력을 시작하는 index를 변경

### **💻 코드 구현 및 피드백**

### **내 코드 (초안)**

**코드 스니펫**

```java
import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int t = sc.nextInt();
        int[] cont = new int[n*3];

        for(int i = 0; i < n*3; i++){
            cont[i] = sc.nextInt();
        }
        int len = n*3;
        int realTime = t%len;
        int startIndex = len - realTime;

        for(int j = 0; j < 3; j++){
            for(int i = 0; i < n; i++){
                if(startIndex == len){
                    startIndex = 0;
                }
                System.out.print(cont[startIndex++]+" ");
            }
            System.out.println();
        }
    }
}
```

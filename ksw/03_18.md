### **내 코드 (초안)**

**코드 스니펫**

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException{
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());
        
        Deque<Integer> d = new ArrayDeque<>();

        int num;

        for(int i = 0; i < N; i++){
            StringTokenizer st = new StringTokenizer(br.readLine());
            String oder = st.nextToken();
            switch (oder) {
                case "push":
                    num = Integer.parseInt(st.nextToken());
                    d.addLast(num);
                    break;
                case "pop":
                    if(d.isEmpty()){
                        System.out.println(-1);
                    }else System.out.println(d.pollFirst());
                    break;
                case "size":
                    System.out.println(d.size());
                    break;
                case "empty":
                    if(d.isEmpty()){
                        System.out.println(1);
                    }else System.out.println(0);
                    break;
                case "front":
                    if(d.isEmpty()){
                        System.out.println(-1);
                    }else System.out.println(d.peekFirst());
                    break;
                case "back":
                    if(d.isEmpty()){
                        System.out.println(-1);
                    }else System.out.println(d.peekLast());
                    break;
            
                default:
                    break;
            }
        }
        
            

        
    }
}


```

### **AI 최적화 코드 비교 및 진단**
```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException{
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder(); // ⭐ 추가

        int N = Integer.parseInt(br.readLine());
        Deque<Integer> d = new ArrayDeque<>();

        for(int i = 0; i < N; i++){
            StringTokenizer st = new StringTokenizer(br.readLine());
            String order = st.nextToken();

            switch (order) {
                case "push":
                    int num = Integer.parseInt(st.nextToken());
                    d.addLast(num);
                    break;

                case "pop":
                    sb.append(d.isEmpty() ? -1 : d.pollFirst()).append('\n');
                    break;

                case "size":
                    sb.append(d.size()).append('\n');
                    break;

                case "empty":
                    sb.append(d.isEmpty() ? 1 : 0).append('\n');
                    break;

                case "front":
                    sb.append(d.isEmpty() ? -1 : d.peekFirst()).append('\n');
                    break;

                case "back":
                    sb.append(d.isEmpty() ? -1 : d.peekLast()).append('\n');
                    break;
            }
        }

        System.out.print(sb); // ⭐ 한 번에 출력
    }
}
```

- **개선된 코드의 효율성 차이:** (시간/공간 복잡도 측면에서 어떻게 개선되었는가?) 비교하고 print하는 시간이 매우 줄어들었음
- **자가 진단:** StringBuilder를 원래 사용하지만 이번 문제에서는 print로도 시간이 많이 걸리진 않을 줄 알았다. 하지만 ai가 바꿔준 코드를 보니 삼항연산자까지 사용해서 시간과 가독성을 더욱 늘릴 수 있다는 것을 깨닳았음.

### **💻 코드 구현 및 피드백**

### **내 코드 (초안)**

**코드 스니펫**

``` java title:'괄호 문자열의 적합성 판단'
import java.io.*;

import java.util.*;

public class Main {

public static void main(String[] args) throws IOException {

BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

String str = br.readLine();

Stack<Integer> s = new Stack<>();

  

for(int i = 0; i < str.length(); i++){
	switch (str.charAt(i)) {
		case '(':
			s.push(1);
			break;
		case ')':
			if (s.size()==0) {
				s.push(0);
				break;
			}else{
				s.pop();
				break;
			}
		default:
			break;
	}

}
if (s.isEmpty()) {
	System.out.println("Yes");
}else System.out.println("No");
	}

}
```

### **수정 및 보완 내용**

첫 입력이 아닌 중간 과정에서도 스택이 비어있는 상태가 될 수 있음. (ex. "()())") 이과정을 처리를 하지 않아 런타임 에러가 나옴

### **AI 최적화 코드 비교 및 진단**

```java
import java.io.*;
import java.util.*;
 
public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String str = br.readLine();
        Stack<Integer> s = new Stack<>();

        for(int i = 0; i < str.length(); i++){
            switch (str.charAt(i)) {

                case '(':
                    s.push(1);
                    break;

                case ')':
                    if (s.isEmpty()) {
                        System.out.println("No");
                        return;
                    }
                    s.pop();
                    break;

                default:
                    break;
            }
        }

        if (s.isEmpty()) {
            System.out.println("Yes");
        } else {
            System.out.println("No");
        }
    }
}
```
- **개선된 코드의 효율성 차이:** 메모리를 더 효율적으로 사용할 수 있게 return을 사용해 준 것을 볼 수 있음. 쓸데 없이 s.push(0)을 하여 낭비하지 않도록 수정함.
- **자가 진단:** 이 문제에서 내가 정확히 이해하지 못했던 개념이나 논리적 맹점은 무엇이었는가? return을 사용할 생각을 하지 못함. if(조건실패){return} 형태의 코드를 짜본 경험이 그동안 없었는데 이번에 알게 되었음.

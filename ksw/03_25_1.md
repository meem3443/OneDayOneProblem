### **1. 문제 핵심 요약**

- [ ] 입력은 무엇인가? (자료형, 개수): 정수
- [ ] 출력은 무엇인가? (포맷, 정답 조건): 정수
- [ ] 문제의 목표를 한 문장으로 정리하면?: 최소값 구하고 다른 원소에서 뺀값들 합해서 출력


### **3. 알고리즘 선택 & 복잡도 예상**

- [ ] 예상 시간 복잡도: O( N logN )
- [ ] 선택한 자료구조: 배열

### **💻 코드 구현 및 피드백**

### **내 코드 (초안)**

**코드 스니펫**

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException{
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());
        StringTokenizer st = new StringTokenizer(br.readLine());

        int arr[] = new int[N];
        int result = 0;

        for(int i = 0; i < N; i++){
            arr[i] = Integer.parseInt(st.nextToken());
        }

        Arrays.sort(arr);
        for(int i = 1; i < N; i++){
            result += arr[i]-arr[0];
        }
        System.out.println(result);
        

     
    }
}
```

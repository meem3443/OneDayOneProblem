### 겹쳐지지 않는 두 직사각형

### **1. 문제 핵심 요약**

- [ ] 입력은 무엇인가? (자료형, 개수): 정수 두개, 졍수형 이차원 배열
- [ ] 출력은 무엇인가? (포맷, 정답 조건): 정수
- [ ] 문제의 목표를 한 문장으로 정리하면?: 겹치지 않는 직사각형 두개 내부에 있는 모든원소의 합, 이 경우의 수중 최대값

### **2. 제약 조건 (Constraints) 분석**

- 시간 제한: 3000ms
- 메모리 제한: 176MB
- 입력 크기(N): 2<= N, M <=5
    - 최소: 2
    - 최대: 5
	- 값의 범위: (Integer 범위 초과 여부 확인) 

### **3. 알고리즘 선택 & 복잡도 예상**

- [ ] 예상 시간 복잡도: O( N^10 )
- [ ] 선택한 자료구조: 이차원 배열
- [ ] 선택한 알고리즘: (Greedy, DP, BFS/DFS, 이분탐색 등) 브루트 포스
- [ ] 근거: (N의 크기를 볼 때 이 알고리즘이 적합한가?) 입력값이 작아서 가능하다.

### **6. 로직 설계 (Pseudo-code)**
 직사각형의 왼쪽 위 오른쪽 아래의 좌표를 기준으로 내부의 합을 계산
 두 직사각형의 합을 구한 상태로 서로 겹치는지 확인
 겹치지 않으면 result 갱신

겹치는지 확인하는 함수
 각 꼭지점의 값을 기준으로 부등호로 확인
 겹치면 참, 안겹치면 거짓 출력

### **내 코드 (초안)**

**코드 스니펫**

```java
import java.io.*;
import java.util.*;

public class Main {
    static int N;
    static int M;
    static int[][] arr;
    public static void main(String[] args) throws IOException{
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken());
        M = Integer.parseInt(st.nextToken());
        arr = new int [N][M];
        int result = -2147483648;

        for(int i = 0; i < N; i++){
            st = new StringTokenizer(br.readLine());
            for(int j = 0; j < M; j++){
                arr[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        for(int x1 = 0; x1 < N; x1++){
            for(int y1 = 0; y1 < M; y1++){
                for(int x2 = x1; x2 < N; x2++){
                    for(int y2 = y1; y2 < M; y2++){
                        int sum1 = sum(x1, y1, x2, y2);

                        for(int a1 = 0; a1 < N; a1++){
                            for(int b1 = 0; b1 < M; b1++){
                                for(int a2 = a1; a2 < N; a2++){
                                    for(int b2 = b1; b2 < M; b2++){

                                        if(!isInterupt(x1, y1, x2, y2, a1, b1, a2, b2)){
                                            int sum2 = sum(a1, b1, a2, b2);
                                            result = Math.max(result, sum1+sum2);
                                        }
                                    }
                                }
                            }
                        }
                    }
                }
            }
        }
        System.out.print(result);

     
    }
    public static int sum(int x1, int y1, int x2, int y2){
        int sum = 0;
        for(int i = x1; i <= x2; i++){
            for(int j = y1; j <= y2; j++){
                sum+=arr[i][j];
            }
        }
        return sum;
    }

    public static boolean isInterupt(int x1, int y1, int x2, int y2, int a1, int b1, int a2, int b2){
        if((x2<a1) || (x1>a2) || (y2<b1) || (y1>b2)) return false;
        else return true;
    }
}
```

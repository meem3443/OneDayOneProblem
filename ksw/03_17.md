### **내 코드 (초안)**

**코드 스니펫**

```java
import java.io.*;
import java.util.*;
 
public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        StringBuilder sb = new StringBuilder();
        int N = Integer.parseInt(st.nextToken());
        int K = Integer.parseInt(st.nextToken());

        Queue<Integer> q = new LinkedList<>();
        for(int i = 1; i <= N; i++){
            q.add(i);
        }
        while (!q.isEmpty()) {
            for(int i = 0; i < K-1; i++){
                q.add(q.poll());
            }
            sb.append(q.poll()).append(" ");
        }
        System.out.println(sb);             
    }
    
}


```

### **AI 최적화 코드 비교 및 진단**
```java
import java.io.*;
import java.util.*;
 
public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        StringBuilder sb = new StringBuilder();

        int N = Integer.parseInt(st.nextToken());
        int K = Integer.parseInt(st.nextToken());

        Deque<Integer> q = new ArrayDeque<>();

        for(int i = 1; i <= N; i++){
            q.addLast(i);
        }

        while (!q.isEmpty()) {

            int rotate = (K - 1) % q.size();  // 핵심 최적화

            for(int i = 0; i < rotate; i++){
                q.addLast(q.pollFirst());
            }

            sb.append(q.pollFirst()).append(" ");
        }

        System.out.println(sb);             
    }
}
```

- **개선된 코드의 효율성 차이:** (시간/공간 복잡도 측면에서 어떻게 개선되었는가?) 반복문에서의 시간낭비를 줄였음. 
- **자가 진단:** 큐의 사이즈로 나눔으로써 for의 반복 횟수를 줄일수 있다는 것을 전혀 생각하지 못했음. K의 값이 커질수록 이렇게 코드를 짜는게 효율적일거 같다는 생각이 듦.

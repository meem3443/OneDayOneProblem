# [문제 이름/번호] 분석

## 1. 문제 핵심 요약

- [ ] 입력은 무엇인가? (자료형, 개수): 첫번째 줄에 정수 m1, d1, m2, d2가 공백을 두고 주어짐
- [ ] 출력은 무엇인가? (포맷, 정답 조건):
      2011년 m2월 d2에 해당하는 요일을 Sun, Mon, Tue, Wed, Thu, Fri, Sat 형태로 출력
- [ ] 문제의 목표를 한 문장으로 정리하면?:
      2011년 m1월 d1일이 월요일이면, 2011년 m2월 d2일은 무슨 요일인지 계산하기

## 2. 제약 조건 (Constraints) 분석

- 시간 제한: 1000ms
- 메모리 제한: 80MiB
- 입력 크기(N):
  - 1 <= m1, m2 <= 12
  - 1 <= d1, d2 <= 31
    (모순된 경우는 나오지 않음)
- 값의 범위: Integer

## 3. 알고리즘 선택 & 복잡도 예상

- [ ] 예상 시간 복잡도: O(N)
- [ ] 선택한 자료구조: 배열
- [ ] 선택한 알고리즘: 단순계산
- [ ] 근거: 단순계산

## 4. 엣지 케이스 (Edge Cases) & 예외 처리

- [ ] 2월부터 다른 달까지

## 5. 로직 설계 (Pseudo-code)

1. 1월 ~ 12월까지 월별 일자를 배열로 선언하기
2. 1월부터 m1-1까지, m2 - 1까지 서로 각각 더하여 총일자 계산하기
3. 이후 각각에 d1, d2 더해주기
4. 둘을뺀뒤에 % 7 하기
5. 해당값만큼 일자 인덱스에서 전진시키기

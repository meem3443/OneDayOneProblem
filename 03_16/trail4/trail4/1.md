# 📝 일일 문제 분석 및 풀이 노트

## [최고의 3x3 위치] 분석

### 1. 문제 핵심 요약
* **[x] 입력은 무엇인가? (자료형, 개수):** 정수 N, N*N 배열
* **[x] 출력은 무엇인가? (포맷, 정답 조건):** 정수
* **[x] 문제의 목표를 한 문장으로 정리하면?:** 일정 범위 내 최대 동전의 합 구하기

### 2. 제약 조건 (Constraints) 분석
* **시간 제한:** 1000 ms
* **메모리 제한:** 80 MiB
* **입력 크기(N):** 최소: 3, 최대: 20
* **값의 범위:** 0 또는 1 (동전 유무)

### 3. 알고리즘 선택 & 복잡도 예상
* **[x] 예상 시간 복잡도:** $O(N^2)$
* **[x] 선택한 자료구조:** 2차원 리스트
* **[x] 선택한 알고리즘:** 완전탐색
* **[x] 근거:** N은 최대 20으로 매우 작아 $O(N^2)$ 연산으로도 1초 내에 충분히 해결 가능

### 4. 수학적/논리적 증명 및 설계 (Core Logic)
* **수식 또는 상태 전이 방정식:** $MaxSum = \max \sum_{i=r}^{r+2} \sum_{j=c}^{c+2} Grid[i][j]$ (단, $0 \le r, c \le N-3$)
* **논리적 타당성 증명:** 3x3 격자가 $N \times N$ 범위를 벗어나지 않는 모든 좌상단 시작점 $(r, c)$를 순회하며 합을 구하므로 전체 탐색 범위 내 최댓값을 보장함.

### 5. 엣지 케이스 (Edge Cases) & 예외 처리
* **N이 최솟값일 때 (3): 시작점이 (0, 0) 하나만 존재하며 정상 작동함.
* **동전이 하나도 없는 경우: 모든 칸이 0이므로 max_c는 초기값인 0을 출력함 (정상).

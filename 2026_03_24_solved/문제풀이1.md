문제 풀이

1) N점수를 입력한다. 그리고 N 점수부터 시작해서 100점까지 1점씩 증가한다.
2) 각 점수가 어떤 등급에 해당하는지 출려한다.
3) 출력 결과는 공백을 사이에 두어야 한다.

두 가지 방법으로 풀었다.

하나는 while을 이용했고, 다른 하나는 for을 이용했다.

for()
- 우선 N을 입력 변수로 지정해둔 다음
for i in range(N, 101)
range범위에 N을 넣는다. 그렇게 된다면, N부터 101까지 반복하는 코드를 만들 수 있다.

그리고 이 for문에 if 코드를 넣어 90점 이상이면 A를 80점 이상이면 B를 출력할 수 있도록 한다.

while()
- if와 마찬가지로 N을 입력 변수로 지정해둔다.
그리고 N <=100 일 때로 조건을 입력한다.
이 상태로 조건문 if 코드를 작성하게 된다면 어떤 규칙도 없이 무한적으로 값이 불어나기에 원하는 답을 얻지 못한다.
그렇기에 N = N + 1 을 통해서 1을 더하고 이에 대한 조건을 if를 통해서 받아 작성한다.

이 if문을 작성하면서도 발생하는 문제가 있다.
*if N >= 90:*
    *print("A", end = " ")*
로 작성하게 된다면 N = N + 1 로 인해서 N을 85로 입력한다면 86으로 값이 저장돼 그에 맞는 결과를 낸다.
다시 말하자면, 85 86 87 88 89 90,
이 아니라 86 87 88 89 90 91 로 나온다. 그렇게 된다면 내가 바라는 코드가 아닌것은 물론이고, 조건에 부합한 코드가 되지 않는다.
(**그렇기에 이 while을 이용한 문은 옳지 못하다**)
하지만 그럼에도 결과를 내려고 한다면, 조건에 90이 아니라 91을 입력하면 된다. 그렇게 된다면 N에 1이 더해졌기 때문에 1더한 값만큼 더해진 상황이라 문제 해결과 일치한 코드가 나온다.
